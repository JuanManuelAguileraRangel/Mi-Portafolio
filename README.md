# Portafolio profesional — Juan Manuel Aguilera

Sitio estático responsivo para GitHub Pages, sin frameworks ni compilación.

## Archivos
- `index.html`: estructura y contenido del portafolio.
- `style.css`: diseño, animaciones y adaptación móvil.
- `script.js`: menú móvil, año dinámico y enlaces de contacto.

## Personalización
1. Abre `script.js` y completa `email`, `github` y `whatsapp` en el objeto `contacto`.
2. Modifica textos, experiencia y proyectos en `index.html`. Los proyectos son ejemplos descriptivos: agrega capturas, enlaces y resultados verificables antes de presentarlos como casos publicados.
3. Ajusta colores en las variables `:root` de `style.css`.

## Vista local
Abre `index.html` en el navegador.

## Publicar en GitHub Pages
1. Crea un repositorio **público** llamado `mi-portafolio`.
2. Sube `index.html`, `style.css` y `script.js` a la **raíz** del repositorio (no dentro de una carpeta adicional).
3. Ve a **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Selecciona **main** y **/(root)** y guarda.
5. Espera la publicación y abre `https://TUUSUARIO.github.io/mi-portafolio/`.

Nota: la tipografía se obtiene de Google Fonts y requiere conexión para verse exactamente igual. El sitio sigue funcionando sin ella.
